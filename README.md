Project Performance Dashboard
Overview

This project is an interactive Excel dashboard designed to monitor project performance across departments.

The dashboard provides insights into:

Project completion progress
Budget performance
Department workload
Project status overview
Features
Dynamic KPI cards
Interactive department slicer
Progress gauge chart
Budget overview visualization
Tasks by department analysis
Status tracking metrics
Tools Used
Microsoft Excel
Pivot Tables
Pivot Charts
Slicers
Conditional Formatting
